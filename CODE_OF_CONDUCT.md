# Código de conducta

## En corto

Trata a la gente bien. Critica el código, no a la persona. Asume buena fe.

## No se acepta

Acoso, comentarios despectivos sobre características personales, publicar
información privada de terceros, y comportamiento sexualizado en cualquier
espacio del proyecto.

## Alcance

Aplica en issues, pull requests, discusiones y cualquier espacio donde alguien
represente al proyecto.

## Cómo reportar

Escribe a quien mantenga el repositorio por mensaje directo o por un security
advisory privado si prefieres que quede registro. Los reportes se atienden en
confidencialidad. Las consecuencias van desde una advertencia hasta el bloqueo
permanente, según la gravedad.

Este documento se inspira en el [Contributor Covenant](https://www.contributor-covenant.org/),
resumido a propósito para un proyecto de este tamaño.
